# toc-project1
This is the Theory of Computation Project 1 repository.
## Background
This project consisted of making a DFA/NFA of an turn-based RPG enemy AI. It was programmed in Godot.
## Details
The automaton simulated in this project is based on a basic turn-based RPG enemy AI. These machines are designed for the enemies in a game to be able to take their turn intelligently. It uses multiple variables to determine what actions to take. For example, a random input compared to the aggression level of the enemy to decide whether it will attack or defend on its turn. The automaton modeled features the most basic decisions an enemy can make on its turn, attacking, defending, and running away.
## How to Run
### In Editor
1. Download Godot v4.7.2 for the OS of your choice.
2. Download this repository to somewhere on your computer.
3. Launch Godot and click import on the top bar of the window.
4. Navigate to the folder containing the downloaded repository.
5. Select the repository folder.
6. Launch into the editor.
7. Select game.tscn from the file system on the bottom left of the editor.
8. Click the run button on the top right of the editor.
9. Make sure you can see the output console as that provides the feedback of the enemy state and decisions.
10. Take your turn by clicking the attack button and test out the machine.
